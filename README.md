# Moviezone


# Overview

This app will allow user to login or register  using Google email (Google auth2)  and registered user will be able to delete update , edit movies into the database.

# Development Environment

.net 8.0
 Visual studio coding
To run this project run  type dotnet run in the terminal
male sure to add google client and sercret id in  appsettings.json
